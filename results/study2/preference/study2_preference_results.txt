
==========================================================================================
STUDY 2 — 'MOST BALANCED INTERFACE' PREFERENCE RANKING + QUALITATIVE ANALYSIS
==========================================================================================
Question : rank the three interfaces by how well each BALANCES immersion and
           motion-sickness mitigation (1 = most balanced).
Coverage : 36/36 complete strict rankings (no ties).
Secondary: best-sickness pick n = 22 (incl. 1 'None'); most-realistic pick n = 26 (not asked systematically; exploratory).
Coding   : 225 coded cells (Participant x Method x Code x Valence), 36 participants, 11 codes in 3 families (data/preference/study2_qual_codebook.md).
Terms    : 'balance' = the ranking; 'perceived' = interview statements/picks;
           'measured' = Delta SSQ / Presence questionnaires. These are not interchangeable.
NOTE     : Study 2 has no Baseline condition — all statements are method-vs-method.

--- 5.1 Equivalence bounds for the pairwise splits (no margin was pre-specified) ---

No equivalence margin was fixed before the data were seen, so no binary 'equivalent'
decision is made. Instead, for each pair we report the tightest symmetric margin around
.50 that a TOST at alpha = .05 would accept (= the farther bound of the 90% CI from .50),
and the same with Bonferroni adjustment over the 3 pairs (96.7% CI). Readers can judge
whether a split of that size is practically negligible.
